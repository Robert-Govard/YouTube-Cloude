# YouTube File Storage

Кодирование и декодирование файлов в видеоформат для хранения данных на видеохостингах.

Программа преобразует любой файл в видео, где каждый кадр содержит цветовые блоки — закодированные байты исходного файла. При необходимости данные шифруются XOR-ключом. Обратная операция восстанавливает оригинальный файл из видео.

## Возможности

- Кодирование файлов любого формата и размера в MP4-видео (1920x1080, 6 FPS)
- Декодирование видео обратно в оригинальный файл
- XOR-шифрование с сохранением ключа в `key.txt`
- GUI-интерфейс с вкладками, выбором файлов, прогресс-баром и встроенной консолью
- CLI-режим с интерактивным вводом или аргументами командной строки
- Автоматический поиск FFmpeg (системный или через `imageio-ffmpeg`)
- Уведомление об успешном завершении операции

## Использование

### GUI (графический интерфейс)

```bash
python main.py
```

Откроется окно с двумя вкладками:

1. **Кодировать** — выбрать входной файл, указать название выходного видео, ввести ключ шифрования (опционально) и нажать «Кодировать»
2. **Декодировать** — выбрать видеофайл, указать папку для сохранения, ввести ключ (если файл был зашифрован) и нажать «Декодировать»

В нижней части окна расположена встроенная консоль, которая показывает весь вывод программы в реальном времени.

### CLI (командная строка)

Запуск без аргументов — интерактивный режим с пошаговым вводом:

```bash
python main.py
```

Запуск с аргументами:

```bash
# Кодировать файл в видео
python main.py encode файл.zip -o video.mp4 -k мойключ

# Кодировать без шифрования
python main.py encode файл.zip -o video.mp4

# Декодировать видео в файл
python main.py decode video.mp4 -o ./восстановленные -k мойключ

# Декодировать без ключа
python main.py decode video.mp4
```

#### Аргументы CLI

| Команда | Аргумент | Описание |
|---|---|---|
| `encode` | `input` | Путь до входного файла |
| | `-o, --output` | Название выходного видео (по умолчанию: `output.mp4`) |
| | `-k, --key` | Ключ шифрования (сохраняется в `key.txt`) |
| `decode` | `input` | Путь до видеофайла |
| | `-o, --output` | Папка для сохранения результата (по умолчанию: текущая) |
| | `-k, --key` | Ключ шифрования (сохраняется в `key.txt`) |

Если ключ не указан, программа попытается прочитать его из файла `key.txt`. Если ключ указан, он будет сохранён в `key.txt` для последующего использования.

## Шифрование

Используется XOR-шифрование с строковым ключом. Операция симметрична — один и тот же ключ используется для шифрования и дешифрования. Без правильного ключа восстановить файл невозможно.

Ключ сохраняется в файл `key.txt` в рабочей директории. При следующем запуске программа предложит использовать сохранённый ключ.

## Принцип работы

1. Файл читается как массив байтов
2. Каждый байт разбивается на два 4-битных блока
3. Каждый 4-битный блок сопоставляется с одним из 16 цветов
4. Цвета размещаются в сетке блоков на кадре 1920x1080 (3 региона с дублированием для надёжности)
5. Кадры собираются в MP4-видео через FFmpeg или OpenCV
6. При декодировании — обратный процесс: цвет блока -> 4 бита -> байты -> файл

## Требования

- Python 3.10+
- FFmpeg (опционально, для лучшего сжатия видео; автоматически подтягивается через `imageio-ffmpeg`)
